# 나날노트 (nanalnote)

나날이 쓰는 교사수첩 웹앱입니다.
교사수첩 프로그램 **[쌔미노트](https://blog.naver.com/powertruth)**(Windows용, 원작자와 무관한 별도 프로젝트)에서 영감을 받아, 그 기능을 웹으로 옮기고 중·고등학교 교과 교사용 기능을 더했습니다.
여러 디자인 테마를 고를 수 있고, 데이터는 **드롭박스에 마크다운(.md) 파일**로 저장합니다.

**앱 주소: <https://progh2.github.io/nanalnote/>**
PC와 휴대폰 모두 쓸 수 있고, 휴대폰은 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.

```
브라우저 (GitHub Pages)  ──PKCE 로그인──►  Dropbox  Apps/<앱 폴더>/2026학년도/*.md
                         (서버 없음, 로그인 정보는 이 브라우저에만)
```

저장소는 세 가지 중에서 고릅니다.

| 저장소 | 설명 |
|---|---|
| **드롭박스 (추천)** | 학년도별 마크다운 파일. 메모장·Obsidian 으로 열리고, Claude(드롭박스 커넥터)가 그대로 읽을 수 있음 |
| 이 브라우저(로컬) | 설치 없이 바로 체험. 이 브라우저에만 저장 |
| 이 컴퓨터 폴더 | 데스크톱 앱 전용. 드롭박스와 같은 마크다운 파일을 고른 폴더(포터블은 USB)에 저장 |

## 데스크톱 앱 (Windows · macOS · Linux)

[Tauri](https://tauri.app)(Rust)로 같은 화면을 데스크톱 앱으로 만듭니다.

**바로 받기 (항상 최신판):**
[Windows 설치 파일 (.exe)](https://github.com/progh2/nanalnote/releases/latest/download/nanalnote-windows-setup.exe) ·
[macOS (.dmg)](https://github.com/progh2/nanalnote/releases/latest/download/nanalnote-macos.dmg) ·
[Windows 포터블 (.zip)](https://github.com/progh2/nanalnote/releases/latest/download/nanalnote-windows-portable.zip) ·
[모든 파일](https://github.com/progh2/nanalnote/releases/latest)

| 운영체제 | 설치판 | 포터블(USB) |
|---|---|---|
| Windows 10/11 | `nanalnote-windows-setup.exe` (또는 `.msi`) | `nanalnote-windows-portable.zip` |
| macOS | `nanalnote-macos.dmg` | `nanalnote-macos-portable.zip` |
| Linux | `nanalnote-linux.deb`, `.rpm` | `nanalnote-linux.AppImage` (+ 옆에 `portable.txt`) |

- 데스크톱 앱은 **이 컴퓨터 폴더** 저장소를 씁니다. 드롭박스와 같은 마크다운 형식이라, 드롭박스 프로그램이 동기화하는 폴더(`Dropbox/Apps/<앱 폴더>`)를 고르면 웹판과 같은 자료를 함께 씁니다.
- **포터블:** 실행 파일 옆에 `portable.txt` 가 있으면 자료와 설정(웹뷰 저장소)을 모두 그 폴더의 `나날노트자료`에 둡니다. 드라이브 문자가 바뀌어도 됩니다. (macOS 는 자료만 USB 에, 설정은 사용자 폴더에)
- 코드 서명을 하지 않아 처음 실행할 때 Windows SmartScreen·macOS Gatekeeper 경고가 나옵니다(릴리스 설명 참고).
- 새 버전 내기: `src-tauri/tauri.conf.json`·`package.json` 의 `version` 을 올려 push 한 뒤 `gh release create v1.2.3 --title "나날노트 v1.2.3" --notes "…"` 로 릴리스를 게시하면, `.github/workflows/desktop.yml` 이 세 운영체제에서 빌드해 그 릴리스에 올리고 위의 고정 이름 파일도 새로 바꿉니다. (이미 있는 릴리스는 Actions → *Desktop apps* → 태그 입력으로 다시 빌드)
- 직접 빌드: Rust + `npm run tauri build` (`npx tauri dev` 로 개발 실행).

## 드롭박스 저장 형식

```
Apps/<앱 폴더>/2026학년도/
  설정.md            교원정보·학교급·일과 시간·기본 시간표·내 수업/교실/학반 목록
  학생명단.md         | 학번 | 학년 | 반 | 번호 | 이름 | 사진 | ID |
  학사일정.md         - 2026-03-02: 입학식 / - 2026-05-04: [휴업] 재량휴업일
  포스트잇.md         ## 메모 1 / <!-- color=yellow x=… y=… --> / 내용
  학사일정자료.md      - [월중] 2026-11 · 11월 월중일정 · 2판 · 원본.pdf · 올림 … · 쪽 p1.jpg, p2.jpg
                     (파일은 학사일정자료/, 연락처자료/ 폴더)
  업무일지.md         - [x] 가정통신문 배부 (작성 2026-03-02, 마감 2026-03-06, 완료 2026-03-04)
  학급요록.md         ## 독서록 / - 등록: / - 완료: / | 학생 | 내용 |
  일지/2026-03-02.md  하루치 수업일지(### 1교시 · 정보 · 1-2 · 컴퓨터실1)·학생출결·출장·노트·상담일지
  사진/10203_홍길동.jpg 학생 사진
```

- 형식만 지키면 파일을 직접 고쳐도 됩니다. 일지 파일에 직접 추가한 `## 메모` 같은 다른 단락은 앱이 지우지 않고 그대로 둡니다.
- 일지는 하루에 파일 하나라서, 여러 기기에서 써도 겹칠 일이 적습니다.
- 다른 기기에서 먼저 고친 파일은 **덮어쓰지 않고 알려 줍니다.**
  새로고침하면 그 내용을 불러오고, 한 번 더 저장하면 지금 기기의 내용으로 덮어씁니다.
- 바뀐 파일만 내려받도록 이 브라우저에 캐시를 둡니다. [연결 끊기]를 누르면 로그인 정보와 캐시가 함께 지워집니다.

### 드롭박스 앱 설정 (개발자용, 한 번만)

[Dropbox App Console](https://www.dropbox.com/developers/apps) 에서 앱을 다음과 같이 설정합니다.
- 종류: Scoped access, **App folder**
- Permissions: `files.metadata.read`, `files.content.read`, `files.content.write`
- Redirect URIs: `https://progh2.github.io/nanalnote/`, `http://localhost:5173/`
- Allow public clients (PKCE): **Allow**

App key는 공개값이라 `src/backends/dropbox.js` 에 기본값으로 들어 있습니다.
`VITE_DROPBOX_APP_KEY` 환경변수로 바꿀 수 있습니다. App secret은 쓰지 않습니다.

## 개발

### 로컬 실행

설치 없이 바로 동작합니다. 데이터는 **브라우저(localStorage)** 에 저장됩니다.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 단위 테스트
```

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. 저장소 **Settings → Pages → Source: GitHub Actions** 를 선택합니다.
3. `main` 브랜치에 push 하면 `.github/workflows/deploy.yml` 이 테스트·빌드 후 자동 배포합니다.

## AI 학사일정 추출

설정 → AI 에서 쓸 AI 를 고르고 키(또는 Ollama 주소)를 넣은 뒤 [모델 불러오기] → [테스트] → [AI 설정 저장].
학사일정 메뉴에 이미지·PDF·HWPX 를 올리면 날짜별 일정을 뽑아 보여 주고, 고른 것만 학사일정에 넣습니다.

- Anthropic: 공식 SDK(`@anthropic-ai/sdk`)를 브라우저에서 직접 사용(`dangerouslyAllowBrowser`), 기본 모델 `claude-opus-5-5`,
  JSON 구조화 출력, 지원 모델에서는 서버 측 거절 대비(`fallbacks: "default"`)를 켭니다.
- OpenAI: Chat Completions(이미지 입력, JSON 응답). Ollama: `/api/chat`(비전 모델 필요, `OLLAMA_ORIGINS` 에 이 사이트 허용).
- 키는 이 브라우저에만 저장되고 PIN 잠금 시 암호화됩니다. 문서 내용은 고른 AI 회사로 전송됩니다.
- 예전 한글 파일(.hwp)은 읽을 수 없습니다. HWPX 나 PDF 로 저장해 올리세요.

## 이 기기 잠금(PIN)

- 설정 → 보안에서 PIN(숫자 6자리)을 정하면, 이 브라우저에 남는 드롭박스 로그인 정보·캐시·로컬 데이터·사진을 PIN 으로 연 키로 암호화합니다.
- 지원하는 기기에서는 지문·얼굴·Windows Hello 로도 열 수 있습니다 (WebAuthn PRF).
- 정한 시간 동안 쓰지 않으면 자동으로 잠깁니다. 헤더의 🔒 로 바로 잠글 수 있습니다.
- 공용 PC 에서는 드롭박스 연결 때 "공용 PC"를 체크하세요. 로그인 정보가 탭에만 남고 탭을 닫으면 사라집니다.
- PIN 을 잊으면 이 기기의 저장 정보를 지우고 다시 연결합니다(드롭박스·컴퓨터 폴더의 일지는 그대로).
- 숫자 6자리는 기기를 통째로 가져간 공격자의 대입을 오래 버티지 못합니다. 기기 자체의 잠금도 함께 쓰세요.

## 개인정보 주의

원본 쌔미노트는 개인정보보호법상 민감정보(상담 내역 등)를 다루기 때문에 교사 PC에만 저장했습니다.
웹 버전은 드롭박스(외부 클라우드)에 저장할 수 있으므로 아래를 꼭 지켜 주세요.
- 나날노트 자료 폴더를 다른 사람과 공유하지 마세요.
- Claude 같은 AI 커넥터에 연결하면 상담 내용이 그 서비스로 전달됩니다. 학교 지침을 먼저 확인하세요.
- `APP_PASSWORD` 는 길고 추측하기 어렵게 정하세요. 공용 PC에서는 사용 후 설정을 지우세요.
  저장소 설정과 비밀번호는 브라우저 localStorage 에 남습니다.
- 학생정보는 학번·학년·반·번호·이름(과 선택적으로 사진)만 넣습니다. 학생 사진은 특히 민감한 개인정보이니 학교·교육청의 정보보호 지침을 먼저 확인하세요.
